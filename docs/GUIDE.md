# AI調査ノート ガイド

このサイトの概要・起動方法・使い方・作り(構造)・機能一覧をまとめたドキュメントです。

- **公開URL**: https://ll726.github.io/ai-research-note/
- **リポジトリ**: https://github.com/ll726/ai-research-note (public)
- **ローカル開発URL**: http://localhost:5310

---

## 1. 概要

いろいろなAIについて調べたことを、カテゴリ別に整理して蓄積していくナレッジベースです。
ブログ型ではなく、トップページをランディングページとした「HP型」の構成になっています。

| 項目 | 内容 |
|---|---|
| 種別 | 静的サイト(SPA) |
| 技術 | Vite + React 19 + TypeScript + Tailwind CSS v4 + shadcn/ui |
| デザイン | Better Design の Linear テーマ(ダーク基調・紫アクセント) |
| ホスティング | GitHub Pages(GitHub Actions で自動デプロイ) |
| 記事数 | 13件 / カテゴリ 9種(2026-08-16 時点) |
| データ管理 | `src/data/articles.ts` に全記事を直書き(DB不要) |

### 設計方針

- **記事の追加は1ファイルの編集だけで完結する**(`src/data/articles.ts`)
- カテゴリ・件数・最新記事・検索インデックスはすべてデータから自動生成
- 画像素材が不要になるよう、カテゴリ色 + アイコンでビジュアルを成立させている

## 2. 起動方法

### 2-1. 公開サイトを見る(推奨・準備不要)

ブラウザで以下を開くだけです。スマホからも閲覧できます。

https://ll726.github.io/ai-research-note/

### 2-2. ローカルで起動する(編集・確認用)

**かんたんな方法**: プロジェクト直下の `サイトを開く.bat` をダブルクリック。
サーバーが起動し、自動でブラウザが開きます(すでに起動中ならブラウザだけ開きます)。

**コマンドで起動する場合**:

```bash
npm run dev
```

起動後 http://localhost:5310 を開きます。黒いウィンドウを閉じるとサーバーも停止します。

> **ポートについて**: 他プロジェクトとの衝突を避けるため **5310番に固定**しています(`vite.config.ts`)。
> `strictPort: true` のため、埋まっている場合は黙って別ポートに移らずエラーになります。

### 2-3. その他のコマンド

| コマンド | 用途 |
|---|---|
| `npm run dev` | 開発サーバー起動(ポート5310) |
| `npm run build` | 型チェック + 本番ビルド → `dist/` |
| `npm run preview` | ビルド結果の確認(ポート5311) |
| `npm run lint` | oxlint による静的解析 |

### 2-4. 初回セットアップ(別PCで動かす場合)

```bash
git clone https://github.com/ll726/ai-research-note.git
cd ai-research-note
npm install
npm run dev
```

## 3. 使い方

### 3-1. 閲覧する

| 画面 | URL | 内容 |
|---|---|---|
| トップ(ランディング) | `#/` | ヒーロー・統計・カテゴリ一覧・最新3記事 |
| 記事一覧 | `#/articles` | 全記事を新しい順に表示。検索・絞り込み可 |
| カテゴリ絞り込み | `#/cat/<カテゴリid>` | そのカテゴリの記事だけを表示 |
| 記事詳細 | `#/article/<記事id>` | 本文・読了時間・同カテゴリの関連記事 |

ハッシュ(`#`)ベースのルーティングなので、URLをそのまま共有・ブックマークできます。

### 3-2. 記事を追加する

1. `src/data/articles.ts` を開く
2. `ARTICLES` 配列の **先頭** に、ファイル内のテンプレートをコピーして追記
3. 保存すると開発サーバーが自動リロードして反映される
4. 公開サイトに反映するには commit して push する

```ts
{
  id: "20260817-01",        // 日付+連番。重複禁止
  title: "記事タイトル",
  category: "coding",       // CATEGORIES の id から選ぶ
  date: "2026-08-17",       // YYYY-MM-DD
  summary: "一覧に出る短い説明(1〜2文)",
  content: `
    <p>本文はHTMLで書く。</p>
    <h2>見出し</h2>
    <ul><li>箇条書き</li></ul>
  `,
},
```

**注意点**

- `id` が重複するとその記事を開けなくなる
- `category` は `CATEGORIES` の id と一致させる(不一致だとカテゴリ表示が出ない)
- `content` はバッククォート文字列。本文中にバッククォートを書くとエラーになるため `<code>` タグを使う

### 3-3. カテゴリを追加する

同じファイルの `CATEGORIES` 配列に1行足すだけで、トップ・絞り込み・件数表示に自動反映されます。

```ts
{ id: "robot", name: "ロボティクスAI", color: "#8b5cf6", description: "説明文" },
```

アイコンを付ける場合は `src/components/CategoryIcon.tsx` の対応表にも追記します(未登録ならタグアイコンが使われます)。

### 3-4. 公開する

```bash
git push
```

push すると GitHub Actions が自動でビルド・デプロイし、数分で公開サイトに反映されます。
**push しないと公開サイトは更新されません。**

### 3-5. 動画の文字起こしを記事化する場合のルール

著作権に配慮し、毎回次の方針で処理します。

- 発言をそのまま引用しない(すべて自分の言葉に書き換える)
- 動画の章立てをなぞらず、独自の構成に再編する
- 宣伝・告知部分は含めない
- 出典(番組名・登壇者など)は事実として明記する
- 未検証の主張・数値は「未検証」と注記する

## 4. 作り(構造)

### 4-1. ディレクトリ構成

```
AI調査/
├─ index.html                  … エントリHTML
├─ vite.config.ts              … ポート5310固定 / @エイリアス / Pages用base
├─ サイトを開く.bat             … ダブルクリック起動用
├─ .github/workflows/deploy.yml … GitHub Pages 自動デプロイ
├─ docs/GUIDE.md               … このファイル
├─ old-site/                   … 移行前の旧静的サイト(参考用)
└─ src/
   ├─ main.tsx                 … Reactエントリ
   ├─ App.tsx                  … ルーティング + ヘッダー/フッター
   ├─ index.css                … テーマ変数・記事本文スタイル・a11y設定
   ├─ data/articles.ts         … ★記事とカテゴリのデータ(通常はここだけ編集)
   ├─ pages/
   │   ├─ Landing.tsx          … トップ(ヒーロー・カテゴリ・最新記事)
   │   ├─ Articles.tsx         … 記事一覧(検索・絞り込み)
   │   └─ ArticlePage.tsx      … 記事詳細(読了時間・関連記事)
   ├─ components/
   │   ├─ Header.tsx           … 固定ヘッダー + ナビ
   │   ├─ ArticleCard.tsx      … 一覧の記事行(ArticleRow)
   │   ├─ CategoryIcon.tsx     … カテゴリid → lucideアイコン対応表
   │   └─ ui/                  … shadcn/ui(Linearテーマ版)
   └─ lib/utils.ts             … cn() ユーティリティ
```

### 4-2. データの流れ

```
src/data/articles.ts
  ├─ CATEGORIES[]  → カテゴリカード / 絞り込みピル / フッターリンク
  └─ ARTICLES[]    → 統計・最新記事・一覧・検索・関連記事
        ↓ sortedArticles() で日付降順に整列
        ↓ categoryMap でカテゴリ情報を解決
      各ページが必要な形に加工して表示
```

記事の追加・カテゴリの追加はすべてこの2配列が起点になるため、他のファイルを触る必要はありません。

### 4-3. ルーティング

`App.tsx` 内の自作ハッシュルーターで、`hashchange` を監視して表示を切り替えます(ページ遷移時は自動で先頭にスクロール)。

| ハッシュ | 表示コンポーネント |
|---|---|
| `#/` | `Landing` |
| `#/articles` | `Articles`(絞り込みなし) |
| `#/cat/<id>` | `Articles`(カテゴリ指定) |
| `#/article/<id>` | `ArticlePage` |

ルーターライブラリを使わずハッシュ方式にしているのは、GitHub Pages のような静的ホスティングでサーバー側のリライト設定なしに動かすためです。

### 4-4. デザインの仕組み

- `src/index.css` に OKLCH のテーマ変数を定義(Linear風のダークテーマ)
- 記事本文(HTML文字列)は `.article-body` クラス配下のスタイルで整形
- カテゴリ色は各カテゴリの `color` を `style` 属性で直接適用し、`color-mix()` で背景の淡色を生成
- 画面上部に紫のグラデーショングロー、スクロールバー・選択色もテーマに合わせて調整

### 4-5. デプロイの仕組み

`master` へ push すると `.github/workflows/deploy.yml` が起動し、`npm ci` → `npm run build` → GitHub Pages へ公開します。
GitHub Actions 上でのビルド時のみ `base` が `/ai-research-note/` になり、ローカルでは `/` のままです。

## 5. 機能一覧

### 閲覧機能

| 機能 | 説明 |
|---|---|
| ランディングページ | ヒーロー、統計(記事数・カテゴリ数・最終更新日)、CTAボタン |
| カテゴリ一覧 | 9カテゴリをアイコン付きカードで表示。記事数も表示 |
| 最新記事 | 直近3件をカード表示(カテゴリ色のバナー付き) |
| 記事一覧 | 全記事を日付降順で高密度リスト表示 |
| 全文検索 | タイトル・概要・本文を対象にインクリメンタル検索 |
| カテゴリ絞り込み | ピルをクリックで絞り込み。件数と説明文も表示 |
| 記事詳細 | 本文レンダリング、カテゴリ色のカバーバナー |
| 読了時間表示 | 本文の文字数から自動算出(約500字/分) |
| 関連記事 | 同カテゴリの他記事を最大5件表示 |
| ページ内ナビ | ヘッダーの固定ナビ(現在地ハイライト)、3カラムフッター |

### 記事本文で使える表現

`<p>` 段落 / `<h2><h3>` 見出し / `<ul><ol><li>` 箇条書き / `<table>` 表 / `<pre><code>` コードブロック / `<code>` インラインコード / `<blockquote>` 引用 / `<a>` リンク / `<strong>` 強調 / `<img>` 画像

### 品質・アクセシビリティ

| 項目 | 対応内容 |
|---|---|
| コントラスト | 全テキストで WCAG AA(4.5:1)以上を実測確認済み |
| 色依存の排除 | カテゴリは色ドット + テキスト名を併記 |
| キーボード操作 | 全リンク・ピル・リスト行に `focus-visible` リング |
| タッチ操作 | タッチ端末ではピル・検索欄が44px以上に自動拡大 |
| モーション配慮 | `prefers-reduced-motion` でアニメーションを無効化 |
| レスポンシブ | 320px幅でも横スクロールなし |
| 空状態 | 検索・絞り込みの結果0件時にメッセージ表示 |

### 開発・運用機能

| 機能 | 説明 |
|---|---|
| ホットリロード | 記事を保存すると即座に画面へ反映 |
| 型チェック | ビルド時に TypeScript で記事データの構造を検証 |
| 自動デプロイ | push だけで公開サイトへ反映 |
| ポート固定 | 5310番固定 + strictPort で衝突を検知 |
| ワンクリック起動 | `サイトを開く.bat` |
| shadcn MCP | `.mcp.json` 設定済み。会話でコンポーネントを追加可能 |

## 6. よくあるトラブル

| 症状 | 原因と対処 |
|---|---|
| ローカルで開けない | 開発サーバーが停止している。`サイトを開く.bat` または `npm run dev` で再起動 |
| ポートが使用中エラー | 他プロセスが5310を使用。`vite.config.ts` の `server.port` を変更 |
| 公開サイトに反映されない | push を忘れている、またはActionsが失敗。`gh run list` で確認 |
| ビルドが型エラーで落ちる | 記事データの項目漏れ。`Article` 型の必須項目を確認 |
| 記事が開けない | `id` の重複、またはURLの記事idが誤っている |
| カテゴリ表示が出ない | 記事の `category` が `CATEGORIES` の id と一致していない |
